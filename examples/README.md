# Examples

This directory will contain worked examples of the Solution Sourcing Kit flow.

Planned examples:

- A complete Build decision flow (SOER → VER → SDR with Build outcome)
- A complete Buy decision flow (SOER → VER → SDR with Buy outcome)
- A fast-path example (SSK skipped with documented justification in KER)

Examples will follow the AIEOS naming convention: `{nn}-{type}.md` (e.g., `01-soer.md`, `02-ver.md`, `03-sdr.md`).
